# 余白書店 — Portfolio Library

原 茉利奈の作品・経歴を3D書店を巡る体験として紹介するGitHub Pagesサイト。

公開URL: https://hrmrn1125.github.io/portfolio_library/

## 操作
- 「書店に入る」→作品を選択→「本をひらく」
- iPhone: 作品一覧をタップ。3D画面のスワイプでも移動可能
- 「経歴・プロフィール」で職務経歴を確認
- 作品詳細から旧ポートフォリオの制作画面へ遷移

## データの出典
実績と職務経歴はユーザー所有の `hrmrn1125/haraport` の公開データを元に構成。元サイトにない実績・成果数値は追加していません。

## バックアップと復元
初期版はブランチ `backup/initial-gallery-2026-11-20` に保存済み。GitHub上の該当ブランチから `index.html` を `main` に戻せます。

## メモ
静的HTML / Canvas WebGL1。外部JS依存なし。実績画像は公開済み旧ポートフォリオのURLを参照しています。

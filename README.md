# 余白書店 — Portfolio Library

原 茉利奈の実績と経歴を、現代美術館のような3D書店で閲覧するポートフォリオ。

公開URL: https://hrmrn1125.github.io/portfolio_library/

## 現在の構成

- ダークトーンの印象的な入口から「書店に入る」
- 入店後は「実績の棚」と「経歴の棚」に分かれた本の背表紙を選択
- 本を選ぶとカメラが移動し、自動で本の見開きが開く
- 見開きページに制作期間、担当範囲、取り組み内容などを掲載
- 不要なボタンを削減し、左上ロゴで入口に戻る
- 公開済みの元ポートフォリオに制作画面への導線を設置

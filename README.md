# Marina Hara — Portfolio

原 茉利奈のポートフォリオ。UI・UXデザイン、AIボットシナリオ設計、制作実績と経歴を紹介します。

公開URL：https://hrmrn1125.github.io/haraport/

## 編集する場所
- `site/index.html`：ページ本体
- `site/style.css`：デザイン
- `site/app.js`：モーダルの原稿・画面操作
- `site/works.json`：作品データ・制作期間
- `site/assets/`：公開用画像

`main` に更新すると GitHub Actions で自動公開されます。外部ライブラリのインストールやビルドは不要です。
旧URL `/haraport/portfolio/dist/` は新しいトップへ案内します。
